# Amazon ML Challenge 2026

Team repository for Amazon ML Challenge 2026.

## Structure

- `data/` — challenge data (raw/processed data is not committed)
- `notebooks/` — exploratory analysis and experiments
- `src/` — reusable training, preprocessing and inference code
- `models/` — trained model artifacts
- `experiments/` — experiment tracking
- `submissions/` — competition submissions organized by day
- `docs/` — methodology and documentation

## Environment

Primary development environment: AWS SageMaker Notebook Instance.

Region: `ap-south-1`

## Workflow

1. Understand the problem and evaluation metric.
2. Establish a reliable validation strategy.
3. Build a baseline.
4. Run controlled experiments.
5. Track every submission.
6. Keep the final code reproducible.
7. Prepare the methodology document and submission package.
