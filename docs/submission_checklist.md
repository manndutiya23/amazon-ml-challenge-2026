# Submission Checklist

## Problem Understanding
- [ ] Problem statement understood
- [ ] Target variable identified
- [ ] Evaluation metric identified
- [ ] Submission format confirmed
- [ ] Train/test row semantics confirmed

## Data
- [ ] Train data inspected
- [ ] Test data inspected
- [ ] Missing values analyzed
- [ ] Duplicate rows checked
- [ ] ID columns identified
- [ ] Categorical features identified
- [ ] Numerical features identified
- [ ] Potential leakage checked

## Validation
- [ ] Validation strategy chosen
- [ ] Local evaluation metric implemented
- [ ] Validation split/group/time logic verified

## Modeling
- [ ] Baseline completed
- [ ] Feature engineering experiments recorded
- [ ] Model experiments recorded
- [ ] Hyperparameters recorded

## Submission
- [ ] Prediction file generated
- [ ] Required columns verified
- [ ] Row count verified
- [ ] No missing predictions
- [ ] Submission saved in correct directory

- [ ] Leaderboard score recorded

## Final
- [ ] Final model/code reproducible
- [ ] README updated
- [ ] Methodology document updated
- [ ] Source code included
- [ ] Final submission tested
- [ ] Submission package/ZIP verified
